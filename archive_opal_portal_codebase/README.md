# Opal Portal - Multi-Service & Luxury Retail Codebase

This folder contains the complete, independent codebase for **Opal Portal** (the service reservation and luxury boutique storefront).

### Purpose:
When creating your second AI Studio project for **Opal Portal**, you can use the code in this directory:
- `OpalPortalApp.tsx` contains the entire multi-service booking engine, provider dashboard, seller hub, order history, and luxury retail storefront.
- It operates completely independently with zero links to the Talent Network.

### Components in this bundle:
- **Client Storefront**: Multi-service categories (Beauty, Handyman, Plumbing, Electric, Roofing, Pest Control, Cloud Kitchen, Party Planning)
- **Luxury Retail**: Department shopping, cart, checkout, delivery & pickup tracking
- **Provider Dashboard**: Schedule management, calendar view, catalog services, appointment approvals
- **Seller Hub**: Product listing manager, inventory, sales orders
- **Order Tracking & Invoices**: Digital tracking barcodes, status timeline, downloadable tax invoices
